# Projet de Certification de Recettes

Une application basée sur Flutter pour la certification et la gestion de recettes culinaires.

## Aperçu du Projet
Ce projet vise à fournir une plateforme robuste et fiable pour les passionnés de cuisine et les professionnels afin de documenter, certifier et partager des recettes. L'application met l'accent sur la fiabilité des données grâce à des modèles immuables et une interface utilisateur intuitive.

## Fonctionnalités
- **Gestion de Recettes** : Un modèle de données complet (ID, titre, ingrédients, instructions, catégorie, image).
- **Fiabilité** : Utilisation de structures de données immuables pour prévenir les erreurs d'état.
- **Support Multi-plateforme** : Grâce à Flutter, l'application est prête pour mobile et web.
